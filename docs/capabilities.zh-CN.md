## 怎么读这张表

- 第 **6、7、11、12、13、15、16、24、25、26** 行是本项目存在的理由。
- 第 5–7 行有重叠：keynote-kit **刻意不用占位符**，因为改画布尺寸后占位符不会重排。
- 第 23–25 行：导出是 Keynote 脚本桥最薄弱的一环，Creator Studio 版本尤其明显。

## 什么时候用什么

| 任务 | 推荐 |
|---|---|
| 批量文字 / 简单页 | keynote-kit |
| 精确版面 | keynote-kit（占位符做不到） |
| 数据表格 | `kk_add_table` |
| 图表与信息图 | `charts` / `diagrams` 渲染后插入 |
| 动画、裁剪、母版背景 | Keynote 界面操作，或等原生 MCP |
