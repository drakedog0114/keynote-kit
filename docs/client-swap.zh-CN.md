# 把已有方案稿换成新客户版本

[English](client-swap.md) · **简体中文**

方案稿大多是复用的：结构、故事线不动，换客户名、换数据、换佐证。这套流程专门干这个——
**保留原版式、原字体、原媒体，不重建**。

真实 59 页稿实测：品牌替换 + 96 处文字改写 + 3 处图片替换 ≈ 20 分钟。

## 一、先拿到可编辑的 Keynote 文件

Keynote 自带的 PowerPoint 导入器，比自己重建强得多：

```bash
osascript -e 'tell application "Keynote" to open POSIX file "/path/deck.pptx"'
```

| 方式 | 耗时 | 还原度 | 视频 |
|---|---|---|---|
| Keynote 原生导入 | **13 秒** | **96.5%** 平均像素相似度，最差页 90% | 8/8 全保留 |
| 逐元素重建 | 30+ 分钟 | 60% | 无法支持 |

剩下 3.5% 是字体替换造成的位移（如 macOS 缺 `微软雅黑`）；结构、图片、色块、背景完全对位。

**换客户不要重建。** 只有目标是「换一套设计」时才重建。

## 二、改文字，保留格式

```bash
python tools/replace_text.py "文稿名" --map rules.json --dry-run   # 预览
python tools/replace_text.py "文稿名" --map rules.json
```

```json
{"replace": [["甲珠宝", "乙珠宝"], ["传统手作", "新工坊"]],
 "regex":   [["月\\s*4-5\\s*千万", "月 1.2 亿"]]}
```

**为什么必须用工具而不是直接 `set object text`**：整段赋值会把多段样式压平——
118pt 标题和 66pt 副标题会塌成同一字号。工具先快照每段的字号/字体/颜色，替换后逐段还原；
对齐方式全程不碰，所以居中和右对齐不会丢。

顺序有讲究：长词放前面（`甲珠宝` 要先于 `甲品牌`）。

## 三、换品牌图片

图片里的文字（照片上烤死的 logo、App 截图、流程图）**文字替换碰不到**。三种处理，按优先级：

| 情况 | 做法 |
|---|---|
| 截图 / 手机界面 | 生成新品牌的 mock 图，塞回同一个 box |
| 烤了 logo 的照片 | 整图替换（或向客户要无 logo 原片） |
| 图里带了客户专有术语的流程图 | 重建成原生页面（见第四节） |

保持版式的替换流程：

1. **先记录**每张图的 `x, y, w, h`，再删。
2. **从大索引往小删**（每删一张索引都会变）。
3. 插入新图后**按记录回填几何**——注意「每页左上角的品牌标识」本身就是一张图，
   它会占掉一个索引，寻址 `image 4` 之前一定要重新列一遍。

Keynote 按创建顺序枚举图片，「品牌标识算一张」是最容易搞错的地方，实测已经踩过。

## 四、正文就是一张整页图的页面

有些页整页就是一张图。如果里面的措辞是客户专有的，把它重建成原生元素，之后还能改：

```python
apply_page(deck, page_no, {"elements": [
    {"type": "card", "box": [34, 196, 356, 44], "style": {"fill": "#1F3A5F"},
     "text": {"title": "触点层 · 流量入口", "titleSize": 17, "titleColor": "#FFFFFF"}},
    ...
]}, mode="append")   # append 保留原有标题
```

然后删掉旧图。用旧图的尺寸当版式参考。

## 五、验收

```bash
# 1) 旧品牌零残留：扫全部文本项 + 演讲者备注
# 2) 全页导出，重点看图片密集页
python -c "from keynote_kit import Deck; Deck('文稿名').export('/tmp/pv','images')"
```

清单：

- [ ] 旧品牌字符串：文本项 + 备注都是 0 命中
- [ ] 数据自洽：一张卡上的粉丝数要和另一张的总数对得上
- [ ] 视频还在（原生导入会保留；删图时容易误中 movie）
- [ ] 正文是整页图的页面：要么重建了，要么明确列为待办
- [ ] 每页品牌标识都在，且没被拉伸

## 六、不要做的事

- 不要用全局正则硬套数字量级，逐个命中都要看一眼。
- 不要声称能 1:1 复刻第三方产品截图，重新生成。
- 不要删掉页面的背景图而正文还按暗色调排版。
- 不要把自己生成的 logo 当成客户官方 VI，明确标注为占位。
